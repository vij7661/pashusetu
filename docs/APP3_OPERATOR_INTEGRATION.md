# APP-3 Operator Integration

The Mandal Centre Operator client is now represented as a Flutter app connected to the verified-weighment and pickup APIs.

## Operator path
Login
→ Centre Dashboard
→ Farmer/Goat/Lot lookup
→ registered scale
→ live samples
→ stable reading
→ lock
→ verification video
→ Farmer review
→ reject/reweigh OR accept
→ Farmer-app acknowledgement handoff
→ QR/receipt generated by Farmer/backend path
→ pickup verification
→ dispute reweigh when authorized

## Trust boundary
The Operator app may capture and submit physical evidence, but the backend remains authoritative for:
- verified weighment session
- locked reading
- transaction state
- reweigh lineage
- audit trail
