# APP-2 Buyer Integration

The approved Buyer UI is now represented as a Flutter client wired to the same backend used by the Farmer application.

## Buyer path
Welcome
→ New / Existing Buyer
→ Home Marketplace
→ Verified Listing
→ Bid ₹/kg
→ backend total offer
→ authoritative server sequence
→ Active Bid
→ Offer Accepted
→ Agreement
→ Funds Secured
→ Transit
→ Delivery Verification
→ Tolerance
→ Settlement or Dispute

## Trust rule
The mobile client is a view/command interface. The backend owns sequencing and state.
